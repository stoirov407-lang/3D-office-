# 3D-office-

Маленький прототип веб‑сцены «AI Virtual Office». Этот репозиторий содержит статическую страницу demo (index.html), которая рисует упрощённый офис с агентами с помощью three.js.

Коротко:
- Как запустить локально: откройте index.html в браузере или используйте простой статический сервер, например:
  - npm i -g serve
  - serve .

Безопасность (ВАЖНО):
- В демо больше нет поля для ввода OpenAI API‑ключа в клиенте — это было потенциально опасно. Никогда не вставляйте реальные секреты в клиентский код.
- Для интеграции с OpenAI (или любыми API, требующими ключи) используйте серверную прокси/бекенд, который хранит секреты и выполняет запросы с сервера.

Дальнейшие шаги (рекомендую):
- Инициализировать package.json и сборку (Vite/React + react-three-fiber) для удобной разработки.
- Добавить простой бэкенд (Express/Nest) для аутентификации, signalling (WebSocket) и проксирования запросов к внешним API.
- Перенести 3D‑ассеты в папку /assets и отдавать через CDN/S3 при необходимости.
